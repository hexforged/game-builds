Download the named Windows ZIP or Linux archive from
[Releases](https://github.com/hexforged/game-builds/releases).
Each release explains what that exact build includes and supplies SHA-256 checksums.

This repository contains public distribution metadata only. Game source and dedicated
servers remain private. GitHub's automatic source archives are not playable downloads.
Release tags here identify distribution metadata; manifests identify the actual game source.
